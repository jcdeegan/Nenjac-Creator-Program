NENJAC CREATOR 4.3: how to run it
=================================
The whole object-show studio in one file: write it, draw it, voice it, score it,
animate it, post it.

THE FILES
  Nenjac Creator/
    index.html             <- the app
    assets/                <- your art, backgrounds, props and music
    manifest.webmanifest   <- these five make it installable as an app
    sw.js                     when it's on a website (GitHub Pages).
    icon-192.png              Leave them next to index.html.
    icon-512.png
    icon-maskable-512.png
    apple-touch-icon.png

ON A WEBSITE (GitHub Pages) = THE BEST WAY
  Anyone with the link just opens it. Art exports work right away (no folder linking),
  the mic remembers its permission, and Chrome offers to install it as an app
  (⚙ Settings → General → Install). It keeps working offline after the first visit.
  To update the site: put the new files in the folder, then in GitHub Desktop type a
  summary, hit "Commit to main", then "Push origin". Live about a minute later.
  Everyone's work saves in their own browser, unless you connect a SHARED SHOW (below).

FROM A FILE (Mac / Chromebook)
  Double-click index.html (Chrome works best). The first time you export art into a
  comic, video or mix, it asks you to link your "assets" folder once.

FIRST TIME?
  Deegs and Starr give you a tour. Skip it any time (Skip, Esc, or click outside twice).
  Bring it back with ? (Help) → Take the tour.

YOUR STUFF IS SAVED
  Automatically, in that browser on that computer. It also saves a restore point every
  day (⚙ → Backup & data → Restore points) in case something gets deleted by accident.
  FULL BACKUP: ⚙ → Backup & data → "Download full backup". One .nenjac file with
  EVERYTHING: scripts, the Bible, drawings, comics, songs, animations, imported media
  and (if you leave the box ticked) voice takes. Restore it on any computer with
  "Restore from a backup". Old .json backups still work.
  The ⚙ button gets a red dot when you're overdue for a backup.
  Only open the app in one tab at a time. If you open a second one, it warns you.

MAKING A DIFFERENT OBJECT SHOW
  ⚙ → General → "Your show" sets the name used on title cards.
  ⚙ → General → "Start a brand-new show" clears the Nenjac scripts and lore (kept as a
  restore point) so you can build your own cast from scratch.

SHARED SHOW (work on one show with your crew, from different computers)
  Syncs through a PRIVATE GitHub repo about every 20 seconds. Not live typing like
  Google Docs, but close: different lines of the same script merge on their own. If
  two people change the SAME line at the same moment, both versions are kept, marked
  with ✂ notes, so you pick one and delete the other.
  Set it up once (the person who owns the show):
    1. github.com/new → name it something like my-show-data → PRIVATE → Create.
       (This is a different repo from the website one. It just holds the show.)
    2. github.com/settings/personal-access-tokens/new → give it a name and an expiry →
       Repository access: "Only select repositories" → pick my-show-data →
       Permissions → Repository permissions → Contents: "Read and write" → Generate.
       Copy the token (github_pat_…). GitHub only shows it once.
    3. In the app: ⚙ → 👥 Shared show → paste my-show-data's name (you/my-show-data)
       and the token, type your name → Connect → "Start the shared show".
    4. "Copy invite + my key" and send it to your crew in a private chat.
  Everyone else: ⚙ → 👥 Shared show → paste the invite code → Connect →
    "Use the shared show". Done. The ☁ button in the top bar shows sync status
    (green = synced, yellow = syncing, red = problem; click it for details + activity).
  What syncs: scripts, the Bible, lore, notes, wheels, character voices, saved moves,
    songs, Pit recordings, drawings, animations, imported media and voice takes
    (files over 45 MB stay on the computer they came from).
  What doesn't: your settings, achievements, Vibe Station uploads.
  Safety: every sync is saved in the repo's history (the "history ↗" link). The key
    is only stored in your browser, never in backups or the repo. Anyone with the key
    can edit the show, so only share it with your crew. If a computer is about to
    delete a lot of stuff from the shared show (a reset, a restored backup), sync stops
    and asks first.
  Your crew members can also use their own GitHub accounts instead of your key: add
    them as collaborators (repo → Settings → Collaborators), then they make a CLASSIC
    token with the "repo" box ticked and use "Copy invite" (without the key).

ON YOUR PHONE
  Open the GitHub Pages link in Safari or Chrome. Tip: Share → "Add to Home Screen"
  makes it an app icon. On a phone you get: 📄 Scripts drawer + the line-type buttons
  across the top of the Writing Desk, a big REC button in the Voice Booth, the Bible,
  notes and the wheels. The Pit, Animate and Art Studio work but are made for a big
  screen. Connect the shared show on your phone too and lines you record there show up
  on your computer.

NEW IN 4.3 (THE MUSICAL UPDATE), QUICK GUIDE
  🎼 Musical Room: the new tab right after the Writing Desk (or the lobby door).
     Musical EPISODES still go in the Writing Desk (Song + Lyric lines). The Musical
     Room is for single songs and full-length musicals.
  🎵 A song: pick a style (46 of them: Broadway, hip-hop/rap, pop/rock, shanties,
     jingles, metal...). Each section is a card. Left of every line: syllable count
     (red = longer/shorter than the style likes) and its rhyme letter (A A B B).
     Rhymes on the right follow the line you're answering. Click a word to drop it in.
     Ctrl/⌘+R = rhymes for the exact word at your cursor (pinned). Tab = next section.
     Choruses are linked: write the first one and the repeats fill themselves.
     Buttons: 🔁 Make a reprise · ✍️ Put in a script · 🎻 Send to The Pit · ⤓ Lyric sheet.
     Duets/group songs say A / B: fill in "🎭 Cast it" in the guide box.
  🎭 A full musical: 🎭 New musical → pick a structure. Drag numbers and book scenes
     between acts. ✍️ Write it opens a book scene in the Writing Desk (stays linked).
     Tabs: Overview, Cast, Motifs & reprises, Stats & check (runtime + script doctor).
     📜 Libretto prints the whole show or saves a .txt.
  ⬆️ Lift mouth: Animate → select a character → 👄 Talking mouth → ⬆️ Lift → ✋ Place on
     stage and drag the yellow line onto the mouth. The top half lifts straight up.
  🎤 Rhyme Battle + 🗯 Who Said It?: Chaos Corner, under Squid Smash.
  💡 Idea inbox: Alt+I anywhere (or the lobby button). 📍 The lobby shows where you left off.
  ✏️ Rename a character everywhere: ⌘K → "Rename". 🎲 Musical Room → Song idea.
  Shared show: songs, musicals and ideas sync like scripts do.

NEW IN 4.2 (THE ALIVE UPDATE), QUICK GUIDE
  🍁 Flaphead + other mouths: Animate → select a character → 👄 Talking mouth → pick a
     style. For Flaphead / Jaw drop / Ventriloquist hit ✋ Place on stage: drag the yellow
     line onto the mouth and the red dot to the back of the head. 🗣 Talk test previews.
     "⭐ Make this X's mouth everywhere" saves it to their Animation profile.
  🪀 Eyes, 🍮 jiggle, 🤬 emotions: same panel, ✨ Emotions, eyes & jiggle. Emotion buttons
     drop at the playhead (lasts their line, or pick a length).
  🧩 Character Creator: Universe Bible → 🧩 Character Creator (or ⌘K). 🎲 for random.
  🎬 Animation profile: open any character in the Bible, scroll to the bottom.
  🎬 Director mode: Animate top bar → 🎬 Director (or tick it in Script → Scene).
  🔔 Sound board: Animate top bar 🔔, The Pit 🔔, or ⌘K "sound board". ＋ adds at the playhead.
  🧅 Onion skin: the onion button next to Auto-key. Selected layer with 2+ position
     keyframes: drag the diamonds on the stage to move them, drag the round dot to bend.
  ⚡ Fast preview: the lightning button (off → while playing → always). 🎞 Queue = render queue.
  🗣 Table Read 2.0: Writing Desk → Read. Toggle recorded takes, sound effects, laugh
     track (click 😂 next to a line to mark it) and a music bed.
  📈 Pace and 🔍 Compare: Writing Desk toolbar.
  🎨 Look & feel: ⚙ Settings → 🎨 Look & feel (themes, size, hide tabs, your shortcuts).
  📥 Drop files on any screen. 📣 Type @Name in a note to ping someone.

NEW IN 4.1, QUICK GUIDE
  📌 Notes: 🗒 in the top bar. A note sticks to where you are (script line, moment in
     an animation, bar of a song, drawing). Lines with notes get a marker; click it.
  📄 Templates: Writing Desk → + New → pick a shape (Shift-click + New = blank page).
  🗣 Hum a melody: The Pit → 🗣 → hum over the band → it becomes a flute track.
  🎯 Pitch fix: The Pit → double-click a vocal region → Strength + Style → Fix pitch.
     "Turn into notes" makes any vocal into an instrument part.
  🎭 Character voices: Voice Booth → 🎭 Character voices → pitch/effect/volume per
     character, applied to every take.
  🎬 Transitions: Animate → FX tab (top of the list) → drop one where two shots meet.
  ⭐ Saved moves: select a layer → Saved moves → save its animation, apply to anyone.
  🟩 Green screen: select imported video/image → Green screen → On.
  🏗 Set Builder: Animate → Sets tab → "Build a new set…" (parallax layers).
  🦾 Arms, legs & mouths: select a character → Arms, legs & mouth → turn them on,
     pick poses (they blend), walk/run/dance moves swing the legs.

WHEEL OF DOOM (Chaos Corner)
  Three real wheels: WHO, WHAT and WHERE. "🔓 Keep this" holds one result while you
  respin the others. ✏️ Edit entries: add your own, switch entries off, paste a whole
  list, pick which characters are on it. ＋ New wheel makes your own (a list, the cast,
  who+what+where, or a hot seat wheel that picks everyone once).
  Also included: Challenge Wheel, Hot Seat Wheel (picks everyone once), Plot Twist Wheel.

WRITING DESK KEYS
  Enter .............. next line (Character → Dialogue → Character…)
  Tab ................ change the line type
  Alt/Option + 1–9 ... jump to Scene / Action / Character / Paren / Dialogue / Transition / Song / Lyric / Note
  Alt/Option + F ..... focus mode (Esc to leave)
  Alt/Option + C ..... summon a cameo
  Cmd/Ctrl + F ....... find & replace
  Cmd/Ctrl + S ....... save a draft snapshot

ART STUDIO + COMIC KEYS
  V select · R rectangle · O ellipse · S shape library · P custom shape (pen)
  L line · T text · U speech bubble · N comic panel · B pencil · I color picker
  H or Space+drag to pan
  Double-click a shape to edit its points · Double-click text or a bubble to type
  Drag the yellow dot on a bubble to aim its tail
  Cmd/Ctrl+Z undo · Shift+Cmd/Ctrl+Z redo · Cmd/Ctrl+D duplicate
  Cmd/Ctrl+G group · Shift+Cmd/Ctrl+G ungroup · [ and ] to change the stacking order
  Arrow keys nudge (hold Shift for 10px) · Cmd/Ctrl+scroll or pinch to zoom
  Palette: click = fill, right-click = outline

VOICE BOOTH KEYS
  R record / stop · Space play the keeper · ↑ ↓ previous / next line
  K keep the newest take · Delete delete the newest take
  The first time, Chrome asks to use the microphone. Click Allow.
  (Opened from a file, Chrome may ask again each session. That's normal.)

THE PIT (music) KEYS: same as Logic
  Space play/stop · R record · Return go to start · , . back/forward a bar
  C cycle (drag in the ruler's bar numbers to set the loop) · K metronome
  ⌘/Ctrl+K Musical Typing (A W S E D F T G Y H U J K = notes, Z/X octave, C/V velocity)
  P piano roll · H chords & sections · X mixer · L lyrics · O loop browser · Y library
  M mute · S solo · T split at playhead · ⌘R repeat region · ⌘D duplicate track
  ⌘C/⌘V copy/paste regions · ⌘B bounce · V "go on" out of a vamp · ⌘Z undo
  Recording vocals: select the vocal track, press R, sing. Wear headphones.
  If takes land a hair late or early, nudge "Latency fix" in the Library (Y).
  Bounces are auto-normalized. "Save to Vibe Station" makes the song usable as music
  in Shorts and the Episode Assembler too.

ANIMATE (episodes) KEYS: same as Premiere
  Space play/pause · J K L reverse / stop / play (tap L again = faster)
  ← → one frame (Shift = 10 frames) · ↑ ↓ jump to the previous / next keyframe or edit
  Home / End start / end · ⌘/Ctrl+K cut the selected clip at the playhead
  C razor tool · V selection tool · Q / W trim the clip's start / end to the playhead
  M marker · T make the selected character talk · + / - zoom the timeline · \ fit
  ⌘C/⌘V copy/paste a layer · ⌘D duplicate · Delete remove · ⌘Z undo · ⌘E export
  Keyframes: click the ⏱ stopwatch next to Position/Scale/Rotation/Opacity, then every
  change makes a keyframe at the playhead. Or leave 🔴 Auto-key on and just drag stuff.
  ▸ next to a layer opens its keyframe rows. The yellow diamonds on the clip itself are
  every keyframe at that moment, so you can retime without opening anything.
  Selecting: click, Shift-click to add, or drag a box across empty timeline. ⌘A = all.
  Drag any selected diamond and the whole selection moves (hold Alt to copy instead).
  Double-click a diamond to type its exact time / value and pick the easing.
  Double-click an empty spot in a keyframe row to add a keyframe there.
  Right-click = easing for everything selected. The bar at the top of the timeline
  also has easing, nudge, Faster / Slower, Copy and Delete for the selection.
  ⌘C / ⌘V copies keyframes to the playhead (onto another layer if it's selected).
  Alt+← → nudges the selection a frame (Shift = 10).
  States: every character has a 🎭 States lane under it. Pick a state in that lane's menu
  and drag across the lane to draw it. Drag a state to move it, drag its edges to change
  the length (it snaps to the dialogue lines, shown as yellow strips). Double-click a
  state for type, start, length (or 0.5s / 1s / 2s… buttons), strength, "Match the line".
  Faces: the main cast talks and blinks out of the box. For any other picture, select it
  and hit "Face rig": draw boxes over the mouth / eyes / brows, or pick a "mouth open"
  or expression image to swap in. Drawings from the Art Studio rig themselves.
  Export makes a real MP4 frame by frame (usually faster than real time). Leave the
  export window open until it says Saved.
  Your episodes and imported media are saved in this browser and included in full backups.

EVERYWHERE
  ⌘/Ctrl+K (or the ⌘ button) = command palette (in The Pit and Animate, use the ⌘ button).
  ? = shortcuts for the screen you're on. The ? button = Help, the tour and What's new.

SHORTS FACTORY
  Videos are rendered frame by frame into a real MP4 (in Chrome). Older browsers fall
  back to recording in real time: keep the tab open and in front while it records.
  Chrome saves .mp4 (works on TikTok, Reels and YouTube Shorts). Older browsers save
  .webm: TikTok and YouTube take it, for Instagram run it through CapCut first.

YOUTUBE / SPOTIFY LINKS
  These sites block their players inside a page opened from a file, so links pop out
  into a small mini window. If nothing opens, allow pop-ups for the page.
